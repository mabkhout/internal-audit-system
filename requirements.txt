# Internal Audit System

A production-minded internal audit platform for managing audit engagements, risks, controls, findings, remediation, and reporting.

## Included features
- Role-based user authentication with JWT
- Department and audit engagement management
- Risk register and control library
- Findings and action tracking
- Reporting summaries and Excel/CSV exports
- SQLite by default for local development
- PostgreSQL-ready configuration for production
- Docker and Compose deployment support

## Quick start

1. Create a virtual environment
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```

3. Start the app
   ```bash
   uvicorn main:app --reload
   ```

4. Open the app
   ```text
   http://localhost:8000/
   ```

Default credentials:
- Username: admin
- Password: admin123

## Environment variables
Create a `.env` file based on `.env.example`:
```env
DATABASE_URL=sqlite:///./audit_system.db
SECRET_KEY=change-this-secret-in-production
ACCESS_TOKEN_EXPIRE_MINUTES=1440
```
For PostgreSQL:
```env
DATABASE_URL=postgresql+psycopg2://postgres:postgres@db:5432/internal_audit
SECRET_KEY=change-this-secret-in-production
ACCESS_TOKEN_EXPIRE_MINUTES=1440
```

## Export features
- CSV export: `/api/reports/export/csv`
- Excel export: `/api/reports/export/xlsx`

## Docker / deployment
```bash
docker compose up --build
```
This starts the API on port 8000.

## PostgreSQL migration
The app is SQLAlchemy-based and compatible with PostgreSQL. Switch the `DATABASE_URL` in `.env` or the deployment environment to a PostgreSQL connection string and restart the service.

## Production recommendations
- Use PostgreSQL instead of SQLite for multi-user deployments
- Add CI/CD pipeline and automated tests
- Enable SSO / enterprise identity integration
- Add document evidence storage and workflow approval status
- Add PDF report generation and scheduled audit exports
